# AI for GTM Systems — GitHub Repo Directory

A curated directory of open-source GitHub repos useful for building AI-powered go-to-market systems — agent frameworks, workflow automation, web/lead data collection, MCP servers into the GTM stack, open-source CRM/support/lifecycle infra, AI outbound tooling, and analytics.

Every repo listed was checked live against the GitHub API (not pulled from training data), so stars and descriptions are current as of the last update.

Open [`index.html`](./index.html) in a browser to view the directory, or enable GitHub Pages on this repo to host it live.

Companion doc: `gtm-agent-inventory.html` (internal, not yet published) — n8n workflow templates + Claude Code GTM agent plugins, curated from `zengfr/n8n-workflow-all-templates` and `gtmagents/gtm-agents`.
